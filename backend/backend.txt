# BloomUP Backend Documentation

**Status:** Pre-Beta Demo Ready  
**Last Updated:** Pre-Beta Freeze

## Overview
Backend built with Node.js, Express, and MongoDB (Mongoose) providing REST API for authentication, user management, child profiles, budget tracking, AI insights, and more.

## Deployment Notes (AWS EC2)

- **Hosting 1 (AWS EC2):** Ubuntu 24.04 EC2 `t2.small` with Elastic IP `52.20.155.43`
- **Reverse proxy:** Nginx serves `/var/www/bloomup/frontend-dist` and proxies `/api/*` to `http://127.0.0.1:8888`
- **Process manager:** PM2 (`pm2 start npm --name bloomup-api -- run start` + `pm2 save`)
- **Env vars:** keep `.env` only on the server  
  - Backend: set `CORS_ORIGIN=https://52.20.155.43,http://52.20.155.43,http://localhost:5173`
  - Frontend: set `VITE_BACKEND_URL=https://52.20.155.43`
- **Deploy steps:**
  1. `git checkout <branch>` / `git pull`
  2. `cd backend && npm install && pm2 restart bloomup-api` (run after every backend pull so dependencies stay current)
  3. `cd frontend && npm install && npm run build`
  4. `sudo cp -r frontend/dist/* /var/www/bloomup/frontend-dist/`
  5. `sudo systemctl reload nginx`
- **After EC2 reboot:** Elastic IP keeps the same URL. Run `pm2 resurrect` (or `pm2 start ...` + `pm2 save`) to bring the API back, then `sudo systemctl reload nginx` if configs changed. Re-apply SSL certs if they were stored outside `/etc/nginx/ssl/`.

### HTTPS setup quick reference
1. Generate/update certs (self-signed for demo):
   ```bash
   sudo mkdir -p /etc/nginx/ssl
   cd /etc/nginx/ssl
   sudo openssl req -new -key selfsigned.key -out selfsigned.csr
   sudo openssl x509 -req -days 365 -in selfsigned.csr -signkey selfsigned.key -out selfsigned.crt
   ```
2. Nginx `/etc/nginx/sites-available/bloomup`:
   - Force HTTP → HTTPS redirect on port 80
   - HTTPS block serves `root /var/www/bloomup/frontend-dist`
   - Proxy `/api/` to `http://127.0.0.1:8888` **without** a trailing slash (`proxy_pass http://127.0.0.1:8888;`)
   - Include common headers:
     ```
     proxy_set_header Host $host;
     proxy_set_header X-Real-IP $remote_addr;
     proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
     proxy_set_header X-Forwarded-Proto $scheme;
     ```
3. Enable the site with `sudo ln -sf /etc/nginx/sites-available/bloomup /etc/nginx/sites-enabled/bloomup`
4. Test & reload: `sudo nginx -t && sudo systemctl reload nginx`
5. Frontend builds must point to the HTTPS origin (`VITE_BACKEND_URL=https://52.20.155.43`)

## API Endpoints

### Authentication (`/api/auth`)
- `POST /api/auth/signup` - User registration
- `POST /api/auth/login` - User login (returns JWT token)
- `GET /api/auth/me` - Get current user (protected)

### Users (`/api/users`)
- `GET /api/users/:userId` - Get user details
- `PUT /api/users/:userId` - Update user (e.g., family name)
- `POST /api/users/:userId/image` - Upload user profile image

### Children (`/api/users/:userId/children`)
- `GET /api/users/:userId/children` - Get all children
- `POST /api/users/:userId/children` - Create child profile
- `GET /api/users/:userId/children/:childId` - Get child by ID
- `PUT /api/users/:userId/children/:childId` - Update child profile
- `DELETE /api/users/:userId/children/:childId` - Delete child
- `POST /api/users/:userId/children/:childId/image` - Upload child image

### Budget (`/api/budget`)
- `GET /api/budget/:userId` - Get user budget
- `POST /api/budget` - Create/update budget
- `GET /api/budget/:userId/expenses` - Get expenses
- `POST /api/budget/expenses` - Create expense
- `PUT /api/budget/expenses/:expenseId` - Update expense
- `DELETE /api/budget/expenses/:expenseId` - Delete expense

### AI Insights (`/api/ai/insights/budget`)
- `GET /api/ai/insights/budget?userId=:userId&start=:start&end=:end`
  - Generates AI-powered budget insights
  - Returns: top spending category, suggestions, predictions
  - Uses OpenAI GPT-4o-mini model

### Articles (`/api/articles`)
- `GET /api/articles` - Get all articles
- `GET /api/articles/:id` - Get article by ID
- `GET /api/articles/category/:category` - Get articles by category
- `POST /api/articles/:id/save` - Save article for user
- `GET /api/articles/saved/:userId` - Get saved articles

### Calendar (`/api/calendar`)
- `GET /api/calendar/events/:userId` - Get events
- `POST /api/calendar/events` - Create event
- `PUT /api/calendar/events/:eventId` - Update event
- `DELETE /api/calendar/events/:eventId` - Delete event

### Vaccinations (`/api/vaccinations`)
- `GET /api/users/:userId/children/:childId/vaccinations/recommendations` - Get recommendations

## Key Features

### Authentication Flow
1. User signs up/logs in → receives JWT token
2. Token stored in `Authorization: Bearer <token>` header
3. `authMiddleware.js` verifies token on protected routes
4. `req.user` populated with user data after verification

### AI Insights Generation
- **Controller:** `aiInsightsController.js`
- **Process:**
  1. Fetches user expenses for date range
  2. Computes category statistics
  3. Sends data to OpenAI GPT-4o-mini with structured prompt
  4. Parses JSON response with insights
  5. Returns: top spending, suggestions, predictions

### File Upload
- Uses Multer middleware for handling file uploads
- Stores files in `uploads/` directory
- Supports receipt images, user images, child images
- Routes: `/api/users/:userId/image`, `/api/users/:userId/children/:childId/image`

### Database Models

#### User Model
- `name`, `email`, `password` (hashed), `familyName`
- `children[]` - Array of ChildProfile ObjectIds

#### ChildProfile Model
- `name`, `dateOfBirth`, `age` (computed), `userId`
- `medicalHistory[]`, `vaccinations[]`

#### Expense Model
- `userId`, `amount`, `category`, `date`, `description`
- `receiptImage` (optional)

#### Budget Model
- `userId`, `totalBudget`, `month`, `year`
- `categoryAllocations[]` - Array of CategoryAllocation

## Notable Behaviors

### Authentication
- JWT token issued on login, validated on protected routes
- `/api/auth/me` returns user and `children` ids; requires `verifyToken`
- Token stored in HTTP-only cookies or Authorization header

### Child Profile Management
- Creating child adds document to `ChildProfiles` collection
- Automatically adds child ID to `User.children` array using `$addToSet`
- Deleting child removes document and `$pull`s ID from `User.children`
- Child `age` computed on create and when `dateOfBirth` is updated

### Budget & Expenses
- Expenses linked to user via `userId`
- Budget allocations stored per category
- Supports receipt image uploads for expenses

### AI Insights
- Fetches expenses for current month by default
- Computes category-wise spending statistics
- Uses OpenAI GPT-4o-mini for generating insights
- Returns structured JSON with top spending, suggestions, and predictions

## Security Considerations

### Authentication
- **Password Security:** Passwords are hashed using bcryptjs before storage in MongoDB
  - Implemented in `authController.js` signup and login functions
  - Uses bcrypt.hash() with salt rounds (10) for secure password hashing
  - Password verification uses bcrypt.compare() during login
- JWT tokens expire after set time
- Protected routes require valid token via `authMiddleware.js`

### File Uploads
- Validate file types and sizes
- Sanitize filenames
- Store uploads securely

### CORS
- Configure allowed origins in `server.js`
- Prevent unauthorized cross-origin requests
