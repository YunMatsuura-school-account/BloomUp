# BloomUP Frontend Documentation

**Status:** Pre-Beta Demo Ready

## External Resources & APIs

### Backend API
- **Base URL:** Configured via `VITE_BACKEND_URL` environment variable
- **Endpoints Used:**
  - `/api/auth/login` - User authentication
  - `/api/auth/signup` - User registration
  - `/api/auth/me` - Get current user data
  - `/api/users/:userId/children` - Child profile CRUD
  - `/api/budget/*` - Budget management
  - `/api/ai/insights/budget` - AI insights and suggestions
  - `/api/articles/*` - Article management
  - `/api/calendar/*` - Calendar events
  - `/api/vaccinations/*` - Vaccination data

### Authentication
- **JWT (JSON Web Tokens):** Stored in localStorage as `accessToken`, `token`, or `authToken`
- **Authorization Header:** `Bearer <token>` format

│   │   └── ...

### Key Components

#### AuthGuard (`src/components/AuthGuard.jsx`)
- Checks authentication status on route access
- Fetches `/api/auth/me` to validate token
- Redirects to `/login` if unauthenticated
- Redirects to `/family-setup` if user has no children

#### Dashboard (`src/components/Dashboard.jsx`)
- Main dashboard page
- Displays BudgetSummary, AIInsights, Calendar, UpcomingEvents, RecommendedArticles
- Uses ChildContext for selected child state

#### AIInsights (`src/components/AIInsights.jsx`)
- Fetches AI-generated budget insights from OpenAI
- Shows loading spinner while fetching data
- Displays top spending category, suggestions, and predictions
- Empty state with Figma-inspired design when no budget data exists
- Session storage caching to prevent redundant API calls
- Uses `useChild` context to get current user

#### BudgetSummary (`src/components/BudgetSummary.jsx`)
- Displays budget overview with donut charts
- Main chart: Full circle showing total spent amount
- Category charts: Four smaller donut charts (70% visible, 30% gap)
- Rounded corners on progress arcs
- Empty state with icon when no budget data exists
- Responsive grid layout

#### UpcomingEvents (`src/components/UpcomingEvents.jsx`)
- Displays upcoming calendar events
- Empty state with calendar icon when no events exist
- Integrates with calendar API
- Navigation to calendar page

## Notable Features

### Authentication Flow
1. User logs in → receives JWT token
2. Token stored in localStorage
3. `AuthGuard` validates token on protected routes
4. All API requests include `Authorization: Bearer <token>` header

### Global Fetch Interceptor
- Located in `App.jsx`
- Automatically attaches JWT token to all fetch requests
- Handles 401/403 responses by clearing tokens and redirecting to login

### State Management
- React Context API (`ChildContext`) for global state (selected child, user data)
- Local component state with `useState` hook

### Styling Approach
- TailwindCSS utility classes for styling
- Custom CSS in `App.css` and `styles/articles.css`
- Responsive design with Tailwind breakpoints

## For Developers

### Adding New Features
1. Create component in `src/components/` or `src/pages/`
2. Add route in `src/App.jsx` if it's a new page
3. Use `AuthGuard` wrapper for protected routes
4. Follow existing patterns for API calls (use fetch with global interceptor)

### Loading States
- Use `useState` for loading state: `const [loading, setLoading] = useState(false)`
- Show spinner pattern:
  ```jsx
  {loading ? (
    <div className="flex items-center justify-center">
      <div className="animate-spin rounded-full h-8 w-8 border-b-2 border-[#238D88]"></div>
    </div>
  ) : (
    <Content />
  )}
  ```

### API Calls
- Use `window.fetch` (global interceptor handles auth headers)
- Base URL from `import.meta.env.VITE_BACKEND_URL`
- Include credentials: `credentials: "include"`
- Handle errors with try-catch blocks
